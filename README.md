The repository looks as follows:
```
math-site/
├── _config.yml              site title, baseurl, Markdown/math settings
├── _layouts/                page layouts
├── assets/css/style.css     styling
├── assets/img               images
├── assets/docs              documents used in the document
└── "".md                    Pages of the Website
```

In case you want to use the repository, please do it and adjust the things to make it your own.<br>
